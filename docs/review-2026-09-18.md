## FINAL READINESS CHECK dan langkah operasional

- **Implemented/verified secara automated:** jalur upload/master, pemilihan objek, SigLIP2/DINOv2 + FAISS + reranking, confirmation, export/reference memory, calibration/evaluation tooling.
- **Blocked oleh data:** threshold no-match nyata dan bukti peningkatan akurasi A–G. Dua query obeng berlabel yang diketahui belum menyediakan sesi positif independen yang cukup untuk tuning dan held-out; dumbbell tetap no-match labelled evidence. Tidak ada threshold production baru.
- **Partially verified:** S3/R2 melalui fake adapter; belum diuji kredensial R2 nyata. UI mouse/touch melalui geometri/state tests; audit ini tidak mengklaim pengujian smartphone fisik. Tesseract optional memakai mocked tests, belum benchmark OCR foto nyata.
- **Not implemented, by design:** online training, paid API, penggantian model, auto-deploy.
- **Operasional:** perubahan kode bertanda signature membuat indeks/policy lama tidak kompatibel. Rebuild dengan dataset reference lengkap pada environment tujuan dan restart worker; jangan gunakan contoh sintetis untuk mengganti indeks aktif. Generasi lama tetap disimpan. Frozen policy harus dikalibrasi ulang terhadap signature/index baru sebelum dipasang.

Perintah dari root repository (jalankan pada environment yang memang akan diperbarui):

```powershell
composer install
py -3 -m venv ai-service/venv  # hanya bila venv belum ada
.\ai-service\venv\Scripts\Activate.ps1
python -m pip install -r ai-service/requirements.txt
npm ci
npm run build
php artisan migrate          # hanya jika migrate:status masih Pending
php artisan search:build-index --include-verified
# Setelah sukses, restart proses FastAPI milik environment tersebut.

php artisan search:export-training "D:\data\training-new.jsonl"
php artisan search:build-dataset "D:\data\training-new.jsonl" "D:\data\dataset-new" --seed=42
```

Rebuild/export bukan bagian deployment otomatis audit ini. Perintah export memerlukan nama output baru dan direktori parent yang tersedia. Detail menjalankan service, evaluasi, tuning/freeze/evaluate tersedia di `visual-sku-workflow.md` dan `final-architecture.md`.
